## What this demonstrates

The page-by-page V1 spec for the Trill follower-side product — Plan A (Discover + Endorse).

Two complete user-journey loops are wired up end-to-end:

1. **Discover → Nominate**: Guide → Creator (unrated) → Nominate form → Confirmation → Account "My nominations" with 4 status states
2. **Self-assessment**: TrillClaw quiz (Q12/30) → Result page (archetype + tier + share card) → continue to Account
